# منصة المعلم التعليمية

منصة تعليمية عربية متكاملة لإدارة الدورات، الطلاب، المعلمين، والتحقق من الحسابات.

## المميزات
- نظام تسجيل دخول متعدد الأدوار
- إدارة الطلاب والمعلمين
- إدارة الدورات
- لوحات تحكم منفصلة لكل دور
- واجهة عربية متجاوبة

## التقنيات
- Frontend: React + React Router + CSS
- Backend: Node.js + Express
- Auth: JWT + bcrypt

## التشغيل السريع

### Backend
```bash
cd server
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd client
npm install
npm start
```

الواجهة: http://localhost:3000
الخادم: http://localhost:5000
